# Self Business OS (working name)

A local-first business program for self-employed people and teams of 1–4: one business core (people, work, money,
timeline, Today) plus activity modules (lecturer & trainer, freelancer, small software company, …) — Arabic and
English, works without internet, several PCs share changes safely.

**Status:** Phase 0 — research and plan finished; no program code yet. Next: Phase 1 (core engine).
